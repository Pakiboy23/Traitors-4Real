# App Privacy answers (App Store Connect)

Keep these in step with `ios/App/App/PrivacyInfo.xcprivacy` and
https://traitorsfantasydraft.online/privacy. A mismatch is a 5.1.1 rejection.

## Tracking

- Does this app use data for tracking: **No**
- Tracking domains: none
- App Tracking Transparency: not used

## Data collected

All four types are **linked to the user**, **not used for tracking**,
purpose **App Functionality** only.

| Type | Why |
|---|---|
| Name | Submitted with a draft or weekly entry so a score can be attributed |
| Email Address | Identifies entries and duplicate submissions |
| Gameplay Content | Draft picks and weekly predictions stored on the player record so the league can be scored |
| Device ID | APNs token, only if the player allows notifications, for lock reminders |

Not collected: location, contacts, photos, browsing history, product
interaction analytics, advertising data, or precise location.

## Uses

- Third-party advertising: **No**
- Developer’s advertising or marketing: **No**
- Analytics: **No**
- Product personalization: **No**
- App Functionality: **Yes** (all four types)
- Other purposes: **No**

## Optional / required

- Name: required to submit an entry; not required to browse
- Email: required to submit an entry; not required to browse
- Gameplay Content: required to submit an entry; not required to browse
- Device ID: optional (notification permission)

## Kids

The app is not directed at children under 13.
